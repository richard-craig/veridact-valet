# Trademarks

The code in this repository is licensed under the [Apache License 2.0](LICENSE). That licence covers the code;
it does not grant rights to the project's names (Apache 2.0, section 6).

"Veridact" and "Veridact Valet" are names held by Richard Craig. They are kept separate from the code so that
banks, agent builders and customers can trust what carries them.

## What you can do without asking

- Use, run, modify and redistribute the code under Apache 2.0.
- Say truthfully that your product or deployment "uses Veridact Valet", "is based on Veridact Valet" or "is
  compatible with the Valet profile".
- Refer to the project by name in articles, talks, comparisons and documentation.

## What needs permission

- Naming a product, service, fork or company "Veridact" or "Valet", or something confusingly similar.
- Using the names or logo in a way that suggests the project endorses, certifies or is operated by you.
- Claiming conformance or certification before a public conformance suite and certification process exist.

## Forks

You are free to fork. A fork that changes how checks, approvals or receipts behave must use a different name,
so nobody mistakes it for the reviewed project.

## Contact

Ask through a GitHub issue. Permission is not unreasonably refused.

## Future

If the project joins a neutral foundation, the names may be transferred to it under that foundation's
trademark policy. That decision belongs to the steering group (see [GOVERNANCE.md](GOVERNANCE.md)).
